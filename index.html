What this version tests
  • MediaPipe Tasks Vision is restored to the exact 1.0.1 setup used successfully in V4.
  • The pose model is explicitly selected with Choose .task model, just like V4. The same pose_landmarker_full.task is included in this ZIP.
  • Uses the same past-frame temporal localization as V5, but first estimates global camera translation and aligns past frames to the target.
  • If the motion crop fails, tries ranked fallback tiles: vertical middle is favored, while horizontal priority moves with timeline position and previous successful detections.
  • Fallback tiles are enlarged before Pose Landmarker, so a small sprinter occupies more pixels.
  • The diagnostic ignores roughly the first and last 1.5 s of the video and never uses future frames.
Everything runs locally in Safari. There is no video-upload code. V6 is a diagnostic experiment, not the final timing algorithm.
